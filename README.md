\# AEB-TTC-ADAS



\*\*AI-Based Automatic Emergency Braking Using Object Detection and Time-to-Collision Estimation\*\*



\## Project Overview



AEB-TTC-ADAS is an experimental Advanced Driver Assistance System (ADAS) designed to detect road users, estimate their distance, and assess potential collision risks.



The system uses computer vision and deep learning to analyze driving videos and support collision-warning and automatic emergency braking decisions.



\## Main Features



\- Real-time object detection using YOLOv8

\- Object tracking and road-scene analysis

\- Monocular distance estimation

\- Time-to-Collision (TTC) calculation

\- TTC estimation and temporal filtering

\- Collision-risk assessment

\- Automatic Emergency Braking (AEB) decision logic

\- Video processing and performance analysis



\## Technologies



\- Python

\- YOLOv8 (Ultralytics)

\- OpenCV

\- PyTorch

\- NumPy

\- Pandas

\- Matplotlib

\- Kaggle



\## Project Structure



\- `AEB-TTC-ADAS.ipynb` — Main project notebook



\## Execution



Open the notebook using Kaggle or Jupyter Notebook and execute the cells in order.



Install the required Python libraries before running the project.



\## Limitations



This is an experimental engineering project. Distance and TTC values are estimates, and the braking decisions are not validated for real-world vehicle safety.
